# Encuesta de conciencia en ciberseguridad – TFG UNPAZ

Aplicación web del Trabajo Final de Grado "Evaluación de la conciencia en Ciberseguridad en los estudiantes de la Universidad Nacional de José Clemente Paz" (Lic. en Gestión de Tecnologías de la Información).

Incluye la encuesta anónima, la página de destino del experimento con código QR y un panel para el investigador.

Stack: Python 3.13, Flask, SQLAlchemy, PostgreSQL (Neon), Bootstrap. Se publica en Render.
